# SIMDA – Sistem Manajemen Dokumen Akademik Siswa

## Deskripsi Project

SIMDA (Sistem Manajemen Dokumen Akademik Siswa) merupakan aplikasi berbasis web yang dikembangkan untuk membantu pengelolaan dokumen akademik siswa di sekolah.

Aplikasi ini bertujuan mempermudah proses pengelolaan data siswa, dokumen akademik, serta pengajuan layanan dokumen oleh siswa. Dengan SIMDA, proses pengajuan dan pengelolaan dokumen dapat dilakukan secara lebih terstruktur dan efisien.

## Fitur Utama

### 1. Admin

- Login admin.
- Dashboard admin.
- Melihat dan mengelola data siswa.
- Menambahkan, mengubah, dan menghapus dokumen akademik.
- Melihat pengajuan layanan dari siswa.
- Menyetujui atau menolak pengajuan siswa.
- Memberikan catatan pada pengajuan yang ditolak.
- Mengelola proses peminjaman dan pengembalian dokumen.
- Melihat notifikasi pengajuan baru.

### 2. Siswa

- Registrasi akun siswa.
- Login siswa.
- Melihat dashboard siswa.
- Melihat dokumen akademik.
- Mengajukan layanan dokumen akademik.
- Melihat riwayat pengajuan.
- Melihat status dan catatan pengajuan dari admin.

## Teknologi yang Digunakan

- **PHP 8.2** – Bahasa pemrograman backend.
- **Laravel 12** – Framework pengembangan aplikasi web.
- **MySQL** – Sistem manajemen basis data.
- **HTML** – Membuat struktur halaman web.
- **CSS** – Mengatur tampilan dan desain halaman.
- **JavaScript** – Mendukung interaksi pada halaman web.
- **Vite** – Mengelola proses build aset frontend.
- **Git dan GitHub** – Version control dan penyimpanan repository project.
